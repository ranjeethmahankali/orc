  Run these commands from the project root.

  For a debug build:

  #+begin_src sh :results drawer
    # For a debug build - configure then build.
    cmake -S c/ -B build/debug -DCMAKE_BUILD_TYPE=Debug
    cmake --build build/debug
  #+end_src

  For a release build:

  #+begin_src sh :results drawer
    # For a release build - configure then build.
    cmake -S c/ -B build/release -DCMAKE_BUILD_TYPE=Release
    cmake --build build/release
  #+end_src

  To generate compile_commands.json (useful for Clangd LSP):

  #+begin_src sh :results drawer
    cmake -S c/ -B build/debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON -DCMAKE_BUILD_TYPE=Debug
  #+end_src

  To run C SDK unit tests:

  #+begin_src sh :results drawer
    build/debug/orc_sdk_tests
    build/debug/deck_ops_plugin_tests
  #+end_src

  or in release:

  #+begin_src sh :results drawer
    build/release/orc_sdk_tests
    build/release/deck_ops_plugin_tests
  #+end_src
